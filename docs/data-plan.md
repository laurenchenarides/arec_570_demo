# Data plan

Companion to the class share at the end of Lecture 5.2. Write one line for
each item. A complete plan is specific enough that a classmate could start the
same search. Keep your plan; Lecture 5.5 builds a data section from it.

| Item | Your project |
|---|---|
| **Outcome or exposure:** the behavior or condition you need to observe | |
| **Approach:** primary, secondary, or combined collection | |
| **Sources and access:** two sources (see [api-catalog.md](api-catalog.md)), each with its access type (API, file download, or license) and whether a key is required | |
| **Unit of observation:** what one row represents, such as county-year or gauge-day | |
| **Open question:** the part of collection you are still working through | |
| **Next step:** one concrete action and when you will take it | |

## Example: this demo project

| Item | Demo project |
|---|---|
| Outcome or exposure | Low-flow days and heat days on the Cache la Poudre River, 2024 growing season |
| Approach | Secondary, combined from public APIs |
| Sources and access | USGS Water Data (API, no key); NASA POWER (API, no key) |
| Unit of observation | Day: gauge-day for streamflow, grid cell-day for weather |
| Open question | How to assign one gauge and one weather grid cell to farms across the county |
| Next step | This week, request 2015 to 2024 for the same gauge and count revised values by year |
